# 🎨 로그몬 (LogMon) UI/UX 디자인 명세서 (Logmon-ui-specification.md)

이 문서는 Streamlit 기반 프론트엔드의 **Modern White Glassmorphism** 테마, 레이아웃 및 완전히 배경이 투명한 3D 아이콘 적용 명세를 규정합니다.

---

## 🎨 1. 컬러 팔레트 및 비주얼 테마 (Modern White Glassmorphism)

기존의 뉴모피즘을 탈피하고, 밝고 화사하며 세련된 화이트톤의 글래스모피즘(반투명 유리 질감)을 메인으로 사용합니다.

* **메인 배경색 (Main Background)**: `#F8FAFC` (아주 화사하고 깨끗한 쿨톤 화이트 배경 위에 은은한 파스텔톤 블러 형태의 그라데이션 그래픽이 뒤쪽에 깔린 느낌)
* **카드 배경 (Glass Card)**: 반투명한 화이트 컨테이너 `rgba(255, 255, 255, 0.4)` 질감에 강력한 백드롭 블러 `backdrop-filter: blur(12px)` 효과 적용.
* **카드 테두리**: 선명한 1px 짜리 화이트 반투명 테두리 `border: 1px solid rgba(255, 255, 255, 0.6)`.

### 타이포그래피 (Typography)
* 기본 폰트로 `Inter` 또는 `SF Pro Display` 스타일의 현대적이고 전문적인 산세리프 서체를 사용합니다. 가독성 중심의 폰트 두께(Weight) 계층화를 적용합니다.

---

## 🗂️ 2. 레이아웃 및 컴포넌트 구성 (Single-Track Architecture)

사이드바가 완전히 제거된 **1920x1080 단일 메인 대시보드 구조 (Single-Track)**를 유지합니다.

### 📁 영역 A: 상단 헤더 (Header)
* **서비스 로고 및 타이틀**: 좌측에 'LogMon' 서비스 로고(3D 로봇 헤드)와 브랜드 타이틀 영역.
* **설치 버튼**: 우측에 푸른색 계열의 그라데이션 및 상시 스스로 발광하며 흔들리는(Pulse + Shake) 효과가 적용된 '에이전트 설치하기' 버튼 배치 (호버 시에는 발광을 줄이고 흔들림 정지).
* **페이지 로드 스크롤**: 화면 로딩 후 스크롤이 가장 상단에 고정되도록 강제하는 스크롤 제어 로직 적용.

### 📊 영역 B: 메인 그리드 구성
* **상단 (스코어 카드)**: 3개의 가로형 에이전트 상태 요약 카드 (가동일수, 누적 데이터, 최근 동기화 시각).
* **중단 (트렌드 차트)**: 은은한 퍼플 및 일렉트릭 블루 그라데이션이 적용된 데이터 시각화 차트 영역.
* **하단 (RAG 챗봇)**: 라운딩 처리가 들어간 깔끔하고 세련된 AI 챗봇 인터페이스 컨테이너.

---

## 🚀 3. 에셋 및 아이콘 제약 조건 (철벽 규칙)

* 평면적인 텍스트 이모지(📅, 🚀 등) 사용을 절대 금지합니다.
* 모든 아이콘 위치는 귀엽고 깔끔한 2D 플랫(Flat) 커스텀 아이콘 플레이스홀더로 배치합니다.
  - 메인 로고: 귀여운 2D 테크/로봇 로고
  - 가동 시간: 2D 귀여운 시계
  - 데이터량: 2D 귀여운 데이터베이스 박스
  - 동기화 시간: 2D 귀여운 동기화 화살표
* **[투명도 필수 규칙]**: 아이콘은 반드시 배경이 투명해야 합니다(No Background). 의도적으로 바둑판 배경 무늬를 넣는 것은 절대 금지되며, 만약 AI가 화이트 단색 배경으로 이미지를 생성했다면 프론트엔드 CSS단에서 `mix-blend-mode: multiply;` 등을 사용하여 배경을 자연스럽게 투명화합니다.
* **[챗봇 인터페이스 규칙]**: 챗봇 타이틀 옆의 아이콘 및 챗 메시지 말풍선 내부의 사용자/AI 아바타 아이콘은 노출하지 않고 생략합니다.
