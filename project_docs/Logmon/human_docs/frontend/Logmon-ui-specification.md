# 🎨 로그몬 (LogMon) UI/UX 디자인 명세서 (Logmon-ui-specification.md)

이 문서는 Streamlit 기반 프론트엔드의 Pastel CSS 테마, 뉴모피즘 엠보싱 비주얼 컨셉, 레이아웃 및 컴포넌트 명세를 규정합니다.

---

## 🎨 1. 컬러 팔레트 (Trendy & Soft Retro Neumorphism)

레트로한 엠보싱 감성은 살리되, 촌스럽지 않고 트렌디함을 잃지 않도록 세련된 파스텔 톤과 입체적인 뉴모피즘을 결합합니다.

* **메인 배경색 (Main Background)**: `#E0E5EC` (뉴모피즘에 최적화된 트렌디한 쿨 그레이 - 세련된 입체감을 살림)
* **사이드바 배경색 (Sidebar Background)**: `#D9E2EC` (조금 더 깊이감 있는 블루 그레이)
* **포인트 컬러 1 (Primary)**: `#829AB1` (현대적인 슬레이트 블루 - 메인 액센트)
* **포인트 컬러 2 (Secondary)**: `#F0B2B6` (빈티지 로즈 핑크 - 레트로 감성 포인트)
* **텍스트 컬러 (Text)**: `#243B53` (명도 대비가 확실한 딥 네이비)

## 🔲 2. 비주얼 컨셉: 소프트 레트로 엠보싱 (뉴모피즘 & 반듯함)

둥근 형태를 남발하는 대신, 반듯한 사각형 구조를 유지하면서 입체감을 주는 디자인을 지향합니다.

### 1) 엠보싱 효과 (Soft Shadow CSS)
컴포넌트(카드, 버튼 등)의 테두리를 날카롭지 않고 반듯한 수준(`border-radius: 4px ~ 6px`)으로 유지하고, 밝은 그림자와 어두운 그림자를 대각선 방향으로 양방향 적용하여 소프트한 입체감을 연출합니다.

```css
/* 튀어나온 입체감 (Embossed / Raised Card) */
.embossed-card {
    background: #E0E5EC;
    border-radius: 12px;
    box-shadow: 9px 9px 16px rgb(163,177,198,0.6), 
               -9px -9px 16px rgba(255,255,255, 0.5);
    border: none;
    padding: 15px;
}

/* 들어간 입체감 (Debossed / Sunken Input) */
.debossed-input {
    background: #E0E5EC;
    border-radius: 12px;
    box-shadow: inset 6px 6px 10px 0 rgba(163,177,198, 0.5),
                inset -6px -6px 10px 0 rgba(255,255,255, 0.5);
    border: none;
}
```

### 2) 타이포그래피 (Typography)
* 기본 폰트로는 가독성이 우수한 고딕 계열(`Noto Sans KR`, `Inter`)을 메인으로 사용합니다.
* 메인 로고나 최상단 헤더 타이틀 등 주요 포인트 텍스트에만 미세한 레트로 감성의 픽셀/모노스페이스 폰트(`Monospace`, `Courier New`)를 부분 적용합니다.

## 🗂️ 3. 레이아웃 및 컴포넌트 구성

화면은 좌우 구분 없이 **단일 메인 대시보드 구조 (Single-Track)** 로 넓고 시원하게 배치합니다. 기존의 사이드바 영역은 완전히 제거합니다.

### 📁 영역 A: 상단 헤더 및 타이틀 영역 (Header)
* **서비스 로고 및 타이틀**: 👾 `LogMon` 타이틀을 화면 좌측 상단에 눈에 띄게 배치.
* **설치 버튼**: 타이틀 우측 영역에 트렌디한 **'🚀 에이전트 설치하기'** 버튼을 배치하여, 클릭 시 해당 설치/안내 페이지로 이동하도록 구현합니다.

### 📊 영역 B: 메인 대시보드 (Main Dashboard)
* **요약 스코어 카드 (에이전트 가동 상태 메트릭)**: 가로형으로 배치되는 3개의 반듯한 엠보싱 카드(`st.metric`).
  * **설치 후 경과일 (가동 시간)**: 📅 "에이전트 가동: X일째" (최초 로그 수집일로부터 지난 날짜)
  * **누적 수집 데이터량**: 📦 "에이전트 자동 수집: 총 X라인 (또는 X MB)"
  * **가장 최신 동기화 시간 (가장 중요! ⭐)**: 🔄 "최근 동기화: X분 전 (정상)"
* **시각화 트렌드 차트**: Plotly / Altair를 이용해 부드러운 파스텔 세이지 그린 컬러 중심의 막대/선 그래프 렌더링.

### 💬 영역 C: 하단 RAG 맥락 챗봇 (RAG Chat Interface)
* **대화창 레이아웃**: ChatGPT의 둥근 말풍선 대신 반듯한 파스텔톤 사각형 카드로 구성.
  * **유저 질문**: 오른쪽 정렬, 트렌디한 빈티지 로즈 핑크 배경 (`#F0B2B6`).
  * **로그몬 답변**: 왼쪽 정렬, 슬레이트 블루 배경 (`#829AB1`).
* **고정형 입력창**: 화면 맨 하단에 엠보싱 처리가 되어 가라앉은 텍스트 입력 바(`st.chat_input`) 배치.

### 📥 영역 D: 에이전트 설치 가이드 페이지 (pages/install.py)
* **접근 라우팅**: 메인 헤더의 '🚀 에이전트 설치하기' 버튼 클릭 시 라우팅.
* **디자인 및 구성**:
  * 상단에 "⬅️ 메인 대시보드로 돌아가기" 라우팅 버튼 배치.
  * 트렌디한 뉴모피즘 엠보싱 카드 내부에 탭(`st.tabs`)을 이용하여 [🍏 macOS / Linux] 및 [🪟 Windows] 환경별 원클릭 설치 스크립트(`st.code`)를 세련되게 안내.
